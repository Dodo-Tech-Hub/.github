# Dodo Tech Hub

Assets, templates and toolkits for Dodo Tech Hub projects.

- `profile/README.md`: organization profile shown on github.com/Dodo-Tech-Hub.
- `ISSUE_TEMPLATE/`, `PULL_REQUEST_TEMPLATE.md`: default community health files for repositories without their own.
- `workflow-templates/`: shared GitHub Actions workflow templates.
- `templates/`: Spec Kit constitution and `AGENTS.md` modules for starting a new project. See `templates/README.md`.
